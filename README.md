# Shatter Showdown: ASCII Rock Paper Scissors

Welcome to **Shatter Showdown**, a terminal-based Rock Paper Scissors game with a creative ASCII twist! Battle your wits against the computer and see if you can become the ultimate Shatter Showdown champion.

## 🎮 Game Features

- **Intuitive Controls:** Choose between Rock, Paper, or Scissors right from your terminal.
- **ASCII Art:** Enjoy hand-crafted ASCII representations for each move!
- **Randomized Opponent:** Face off against the computer in each round.
- **Instant Feedback:** Immediate results and outcomes after every play.

## 🚀 Getting Started

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/your-username/shatter-showdown.git
   cd shatter-showdown
   ```

2. **Run the Game:**

   Make sure you have Python 3 installed.

   ```bash
   python3 shatter_showdown.py
   ```

3. **How to Play:**

   - When prompted, type:
     - `0` for Rock
     - `1` for Paper
     - `2` for Scissors
   - See your move and the computer's move rendered in ASCII art.
   - Find out if you win, lose, or draw!
